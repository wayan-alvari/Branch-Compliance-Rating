# Independent implementation

Branch Compliance & Rating is an original personal portfolio application built
from generic assessment concepts and public platform documentation. No employer
repository, code, schema, scoring system, terminology, data, design, screenshot,
branding, or business asset is an input to its implementation.

All scenarios, branches, criteria, responses, evidence fixtures, and results are
fictional. The decimal weighted-average formula is a transparent portfolio
example, with no regulatory or certification authority.

Dependencies come from their official public NuGet and npm distributions. Their
licenses are separate from the MIT license on original repository code; see
`THIRD-PARTY-NOTICES.md`. Local configuration, uploads, databases, build output,
and private build-contract documents are excluded from Git. Delivery checks
include inspection of the tracked tree and complete Git history.
